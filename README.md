Приложение для поиска песен , плейлистами, избранными треками, воспроизведением фрагмента песни.
=====================
Приложение реализовано на основе музыкальной базы itunes.apple.com. Юзер имеет возможность получить список песен по запросу в поисковой строке, может добавить трек в избранное, создать плейлист с фото, названием и описанием и добавить или удалить из него трек, прослушать тестовый фрагмент (30 секунд). Так же пользователь видет на экране плеера всю информацию о треке, например, год создания, автора, авльбом и т.д.
