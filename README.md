h1 Приложение для поиска песен , плейлистами, избранными треками, воспроизведением фрагмента песни.
=====================
Данное приложение реализовано с использованием открытого API "iTunes". Сохранение песен в избранное, также хранение плейлистов и песен в созданных плейлистах реализовано с помощью Room.
Благодаря этим фичам, я научилась работать с базой данных. Приложение в основном написано с использованием фрагментов, применяется подход Single Activity.
